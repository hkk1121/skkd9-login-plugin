# 九号避难所登录插件

《九号避难所》（Steam）免退游切换账号、多账号自动签到，并提供局内 / 城镇信息框架的第三方玩家辅助插件。

## 快速开始

1. 退出游戏，运行 `SKKD9-Login-Plugin.exe`，按界面提示安装插件（需要 Windows 10 / 11 64 位）。
2. 启动游戏，在原登录界面输入账号密码并勾选「记住密码」，登录一次即会自动收录；再登录其他账号即可收录更多。
3. 之后在登录页或 Esc 菜单的「账号」下拉框中选择账号，点「确认切换」即可。
