## 主要功能介绍

### 1. 游戏内快速切换与管理账号

- **免退游切换**：在游戏登录页和局内 Esc 菜单中提供「账号」下拉框。选中目标账号后点击「确认切换」，插件会直接调用游戏原生的返回标题及登录流程完成换号，无需退出并重启游戏。
- **删除账号保护**：登录页的账号面板提供「删除账号」按钮。为防止误触，选中账号后需连续点击两次（「删除账号」变为「确认删除」后再点一次）才会从列表中移除；中途切换下拉框选项会取消删除状态。若删除的是游戏当前正在记住的账号，会一并清除游戏内的登录记忆，下次登录该账号需重新输入密码。
- **面板自由缩放与隐藏**：切换账号窗口支持用鼠标拖拽边框调整大小（登录页和 Esc 菜单都可拖右侧或底边，拖拽右下角可双向调节）。整个窗口与文字会按比例同步缩放（0.6～3 倍；没调过时按屏幕高度取默认比例，1080p 为 1 倍、4K 为 2 倍），并自动记忆尺寸。Esc 菜单里的窗口放在屏幕左侧、垂直居中，展开后放不下时会自动上移，不挡游戏底栏。你也可以在启动器「设置...」中绑定自定义快捷键（如 `Ctrl+F8`），在游戏内随时隐藏或唤出账号面板，修改快捷键后无需重启游戏即可生效。

### 2. 多账号自动签到与定时任务

- **一键轮巡签到**：在游戏完全退出的状态下，点击启动器的「自动签到」，程序会通过 Steam 启动游戏，按顺序登录所有已保存的账号并进入世界（默认进入角色选择界面已选中的角色，未选中则进第一个），停留数秒完成签到后自动切换下一个账号，全部完成后自动退出游戏并展示结果汇总。你也可以随时点击「查看签到结果」回顾记录。
- **每日定时签到**：在启动器中设定时间并点击「创建每日任务」，即可交由 Windows 计划任务在每天指定时间自动执行签到（点击「删除任务」可取消）。
- **使用注意**：定时任务要求电脑处于开机且已登录 Windows 的状态，同时 Steam 能够正常运行。若移动了 `SKKD9-Login-Plugin.exe` 的存放位置，请重新创建每日任务。自动签到运行期间**请勿手动操作游戏窗口**；若某账号下无角色或加载超时，结果会记为失败。签到全部结束后，游戏默认记住的是最后一个签到的账号，下次手动登录时请留意。

### 3. 局内信息框架（海克斯监测）

- **实时状态与槽位排序**：在对局中实时显示海克斯持有数量以及实时状态/叠层数据。列表严格按照游戏底部技能栏的槽位顺序排列，并将持有数量与叠层数分别展示；对于暂不支持的实时状态会明确标注，若暂未读取到槽位则会提示顺序未就绪。
- **锁定、编辑与自定义**：
  - 默认快捷键：键盘上排数字键 `5`（非小键盘）显示/隐藏面板，上排数字键 `4` 切换面板编辑/锁定状态，与城镇框架共用。游戏内输入框正在输入时快捷键不响应。
  - 面板默认处于锁定状态。按 `4` 或勾选标题栏的「面板编辑模式」后，可拖拽标题栏移动位置、拖拽边框调整大小，再次按下即可锁定；导航、滚动和其余设置在锁定时也能直接用。标题栏的「隐藏」只在本次运行内隐藏面板，按 `5` 即可恢复。
  - 在游戏内框架的「设置」页中，支持调整界面整体缩放（60%～200%）、背景透明度（0%～100%，每档 5%，默认 15%，只影响黑色底板；启动器设置里也能调）以及修改快捷键。
  - 在启动器 EXE 的「设置...」中，可控制局内面板的总开关、勾选显示项目、修改快捷键或一键重置面板布局。

### 4. 城镇信息框架（玩家选取、传送、公会与好友）

- **独立控制与布局**：城镇框架拥有与局内框架完全独立的布局和配置，分别保存。默认按键盘上排数字键 `5` 显示/隐藏，按上排数字键 `4` 切换面板编辑/锁定状态（与局内框架共用同一套键）。标题栏的「隐藏」按钮只在本次运行内隐藏，不会停用框架；彻底停用请在启动器 EXE 设置中关闭。左侧导航树分为「城镇信息 › 人物信息 / 传送」「公会 › 公会奖励 / 本周战场」和「设置」。
- **常驻点选与框选交互**：城镇面板「人物信息」下的「选择玩家（常驻）」默认开启，**无需先进入编辑模式**即可直接交互。在城镇中用鼠标左键普通点击其他玩家即可选中，按住 `Ctrl+左键` 拖动可进行框选，并在候选列表中切换查看不同玩家的详情。点击空地时会将操作留给游戏本身，不会清除当前已选中的目标；你也可以在面板中随时关闭常驻选择或手动清除目标。当游戏相机或相关数据不可用时，插件会自动放弃接管选人操作，避免干扰正常游玩。
- **原生快速传送（「传送」页）**：城镇框架默认打开「传送」页，列出游戏原生快速传送当前可用的目的地，点击即可传送。传送前仍由游戏自己检查战斗、对话、加载等限制，不可用的目的地会显示原因；传送进行中或原生快速传送面板打开时，插件不会重复发起。游戏自带的快速传送入口和快捷键保持不变。二楼建筑条目显示等级和升级剩余时间，厨房条目列出每个灶台的制作状态；主城 NPC 名字按游戏头顶铭牌颜色显示，框架够宽时目的地排成两列。
- **传送设置**：在框架「设置」页的「传送功能」分支勾选要显示在传送页的目的地，按楼层和目的地分别保存，新出现的目的地默认勾选。传送页里的「点击空地会切回传送页面」开关可单独开启或关闭。
- **人物右键好友菜单**：在「人物信息」页的候选玩家按钮上点右键打开菜单，按好友状态提供私聊、去他家串门（对方离线时禁用）、发邮件、举报、删除好友（3 秒内点两次才生效）、申请添加好友、同意 / 拒绝 / 撤回好友请求。一次只处理一个请求，结果以游戏返回的提示和好友列表变化为准，游戏不回传原因时会如实说明。菜单打开时点框架外会关闭菜单，但游戏仍可能同时响应这次左键（见本次更新的「已知限制」）。
- **公会奖励与本周战场**：「公会奖励」页显示公会名、本周经验、签到、今日任务和每周目标各档，「一键领取」按「签到 → 今日任务 → 每周目标各档」逐项领取，结束后汇总「成功 N 项，跳过 K 项，失败 M 项」；读不到的数据如实标注并禁止领取。「本周战场」页显示周次、阶段、报名和分组，条件满足时「进入战场」可用，需 3 秒内二次确认，条件不满足会逐项写原因。两页约每 5 秒自动刷新，也可以手动「刷新」。
- **客观展示同步数据**：面板会展示从客户端同步到的玩家姓名、角色标识、原始称号标识、等级（未同步时如实标注）以及外观对应的名称。**特别说明**：面板显示的“外观”仅代表当前渲染的显示外观，不能直接当作该玩家的真实装备；对于武器、装备品质、等级、词条等未经核实的信息，插件绝不会将其显示为“已获取”，未同步的数据也会明确标记状态。

### 5. 面板设置同步机制

- 在启动器或面板中修改局内/城镇框架的设置后，约 1 秒左右即可自动同步生效，无需重启游戏；若保存失败会提示重试，若设置的快捷键存在冲突则会阻止保存。

## 首次安装与使用指南

### 1. 系统环境与安装

- **运行环境**：插件本体为 64 位（x64），需要 **Windows 10 / 11 64 位** 操作系统，并依赖系统自带的 `.NET Framework 4.x`。
- **单文件启动器**：下载 `SKKD9-Login-Plugin.exe` 后直接运行。启动器采用暖橘配色与圆角卡片布局，支持高分屏按比例缩放。程序会自动定位 Steam 中的游戏安装目录；如果未能自动找到，也可以手动浏览选择 `SKKD9.exe` 所在的文件夹。
- **安装与卸载**：**执行安装、升级或卸载操作前，请务必先退出游戏。** 插件采用非侵入式设计，仅向游戏目录新增两个插件 DLL 文件，不会替换任何游戏原始文件。卸载时，程序会根据首次安装时的记录恢复原有的同名文件或彻底删除插件文件，让游戏目录恢复原状（卸载时默认保留你已保存的账号列表）。

### 2. 如何收录账号

1. 安装插件后启动游戏，在游戏原生登录界面输入你的第 1 个账号和密码，**务必勾选游戏自带的「记住密码」**，然后正常登录进入游戏一次，插件即会自动收录该账号。
2. 当你需要添加第 2 个账号时，返回游戏登录页，直接在原登录框输入新账号和密码（同样勾选「记住密码」）并登录一次，新账号也会被自动收录到下拉列表中。
3. 收录完成后，后续即可直接通过登录页或 Esc 菜单的插件下拉框一键切换。

## 更新、版本保护与数据说明

### 1. 自动更新与代理设置

- **检查更新**：每次打开启动器 EXE 时，程序都会自动检查是否有新版本，旧版本可直接在线更新至最新版。你也可以在启动器中复制专用的 **Steam 启动选项** 填入 Steam 游戏属性中，实现每次通过 Steam 启动游戏前先自动检查更新（若移动了启动器 EXE 的存放位置，请重新复制并设置 Steam 启动选项）。
- **HTTP 代理支持**：如果国内网络访问 GitHub 较慢导致检查或下载更新失败，可在启动器「设置...」中手动填写本机代理软件的 HTTP 代理地址（例如 `http://127.0.0.1:7890`；留空则默认使用系统代理）。修改代理并保存后会立即测试检查一次更新；若仅修改了快捷键而未改动代理设置，保存时不会额外弹出更新检查。

### 2. 版本不一致自动暂停保护

- 启动器默认开启「游戏版本与插件不一致时自动暂停插件」（可在「设置...」中关闭）。
- 当游戏更新而插件尚未发布适配版本时：如果你打开本启动器或通过配置了启动选项的 Steam 启动游戏，程序会先把插件从游戏目录中撤出，让你能正常进入游戏，无需手动卸载；即便直接从 Steam 裸启动游戏，插件检测到客户端版本不匹配也会自行退出，不会留在游戏内运行。待插件发布适配更新并升级启动器后，会自动将插件重新装回游戏目录。

### 3. 账号隐私与本地数据

- **无明文密码**：插件仅保存账号名称以及由游戏客户端自身加密生成的登录记忆数据，**绝不会将你的明文密码写入账号列表**。
- **本地存储与备份**：插件的本地配置与数据存放在 `%LOCALAPPDATA%\SKKD9AccountSwitcher\` 目录下。此外，每次打开启动器（或配置了 Steam 启动选项并在退出游戏后），程序都会将账号列表自动备份到启动器所在文件夹旁的 `账号备份.txt`。
- **分享警告**：`账号备份.txt` 中包含加密的登录记忆，该加密数据绑定了当前电脑与当前 Windows 用户环境，仅限在原电脑原用户下恢复使用。**请妥善保管，切勿将带有 `账号备份.txt` 的文件夹打包分享给他人。**

### 4. 安全提示与免责声明

- 本程序没有代码签名。
- 本项目属于第三方玩家辅助工具，与《九号避难所》游戏官方没有任何关联。使用第三方插件可能存在未知的兼容性或账号风险，作者不对工具的绝对安全性作任何承诺，请玩家自行评估后使用。
