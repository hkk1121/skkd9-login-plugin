# 九号避难所登录插件

hkking 的九号避难所登录插件发布页，这里只提供程序下载，不含源码。

九号避难所（Steam）的账号切换插件：在登录页和游戏内 Esc 菜单里加一个「账号」下拉框，选好账号点「确认切换」就能换号。切换走游戏自己的返回标题、登录流程，游戏不用退出，也不用重新输入密码。还能一键（或每天定时）把所有账号依次登录进游戏完成每日签到。

> 作者：hkking，使用 AI 制作（vibe coding）

## 下载安装

1. 打开 **[Releases](https://github.com/hkk1121/skkd9-login-plugin/releases/latest)**，下载最新的 `SKKD9-Login-Plugin.exe`，放在任意文件夹里（比如桌面）。
2. **先退出游戏**，双击运行，点「安装 / 更新插件」。程序会自动找到 Steam 里的游戏目录，找不到时点「浏览...」选择 `SKKD9.exe` 所在的文件夹。
3. 从 Steam 正常启动游戏即可。

需要 **Windows 10 / 11（64 位）**，不需要管理员权限，也不用另外装运行库。

> 程序没有代码签名，运行时 Windows 可能提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」即可。插件通过游戏目录里的 `winhttp.dll` 随游戏加载，个别杀毒软件可能误报，请放行。

## 使用

1. 先用游戏原来的登录界面登录每个账号，**勾选「记住密码」**，正常登录一次。插件会自动把这个账号记下来，面板上显示「已记录账号：xxx」。
2. 想加第二个账号：游戏内菜单点「返回标题」，用第二个账号同样登录一次。
3. 之后切换账号：
   - **登录页**：展开左上角面板里的「账号」下拉框 → 选择账号 → 「确认切换」
   - **游戏内**：按 Esc → 左下角「切换账号」 → 展开「账号」下拉框 → 选择账号 → 「确认切换」。游戏会返回登录页并自动登录，然后进入角色选择
4. 登录失败时，面板会显示游戏返回的错误，重新选择账号即可。

在下拉框里选中账号只是改变选择，点「确认切换」才会真正换号；切换过程中按钮会暂时禁用。

**调整窗口大小**：用鼠标拖切换账号窗口的边框（登录页拖右边或下边，Esc 菜单里拖右边或上边，拖角上的 ◢ / ◥ 两个方向一起调），整个窗口连文字一起放大缩小，大小会记住。

**隐藏窗口**：在程序里点「设置...」，点一下「隐藏快捷键」框，按想用的组合键（如 `Ctrl+F8`）后保存。游戏里按这个键隐藏切换账号窗口，再按一次显示出来。改快捷键不用重启游戏。

## 自动签到

游戏每天进入游戏世界就算签到，程序可以帮你把所有账号都签一遍：

1. **先退出游戏**，在程序里点「自动签到」。
2. 程序会通过 Steam 启动游戏，按账号列表的顺序依次登录每个账号、进入角色（角色选择界面默认选中的那个），在游戏里停留几秒后换下一个账号。
3. 全部签完后游戏会自动退出，程序弹出每个账号的结果（成功、失败或超时）。之后点「查看签到结果」还能再看。

**每天定时签到**：在「创建每日任务」左边选好时间（比如 08:00），点「创建每日任务」。之后每天到这个时间，Windows 会自动运行签到，不弹窗口，结果在「查看签到结果」里看。要求电脑开着、已经登录 Windows，且游戏没在运行。不想要了点「删除任务」。

注意：

- 签到时请不要操作游戏窗口，等它自己跑完。每个账号最多等 2 分半，超时会跳过；账号没有角色会记为失败。
- 签完后游戏记住的是最后一个签到的账号，下次手动进游戏时如果想用别的号，在登录页切换一下即可。
- 程序换了位置后，要重新点一次「创建每日任务」。
- 游戏更新后插件还没适配时，自动签到不会进行。

## 程序界面

| 按钮 | 说明 |
|---|---|
| 安装 / 更新插件 | 把插件装进游戏目录；已经装过时覆盖成当前版本 |
| 卸载插件 | 删除插件文件；安装前目录里原本就有同名文件的，会还原回去。账号列表保留 |
| 启动游戏 | 通过 Steam 启动九号避难所 |
| 检查更新 | 手动检查一次新版本 |
| 打开发布页 | 用浏览器打开 Releases 页面 |
| 复制 Steam 启动选项 | 设置每次启动游戏时自动检查更新，见下面「更新」 |
| 设置... | 填写检查更新用的代理地址（见下面「更新」）；设置游戏里隐藏切换账号窗口的快捷键 |
| 自动签到 | 启动游戏，把所有已保存的账号依次签到一遍后自动退出，见上面「自动签到」 |
| 查看签到结果 | 显示最近一次签到每个账号的结果 |
| 创建每日任务 / 删除任务 | 每天在选好的时间自动签到 / 取消每日签到 |

界面上会显示插件是否已安装、是否是当前版本，以及当前的游戏版本是否已适配。游戏运行时不能安装和卸载，请先退出游戏。

## 更新

每次打开程序都会自动检查一次，发布了新版本会弹出「发现新版本」，显示这次的更新说明。点「是」后在后台下载，下载完会替换程序自己并重新打开，已经装好的插件也会自动跟着更新。

**想每次玩游戏都自动检查更新**：点「复制 Steam 启动选项」，在 Steam 库里右键九号避难所 →「属性」→「通用」→「启动选项」，粘贴进去。之后每次从 Steam 启动游戏，都会先检查更新、装好插件，再启动游戏。程序换了位置后需要重新复制一次。

国内访问 GitHub 不稳定，检查或下载失败时：

- **填代理**：点「设置...」，在「代理地址」里填本机代理软件的 HTTP 端口或混合端口，如 `http://127.0.0.1:7890`（Clash、v2rayN 等端口不同，以软件里显示的为准），点「保存」后会马上用这个代理检查一次更新。检查更新和下载新版本都走这个代理，从 Steam 启动时也一样；留空则使用系统代理。
- **手动下载**：点「打开发布页」用浏览器下载新的 exe，替换掉旧的即可。

> 「设置」从 v1.0.1 开始才有。v1.0.0 用户如果检查不到更新，先打开系统代理，或者到 Releases 手动下载一次新版本。

## 常见问题

**游戏更新后切换账号不见了 / 界面显示游戏版本未适配？**
插件只适配特定版本的客户端。游戏更新后插件会自动跳过接入、只写日志，不影响正常游戏；等插件发布适配新版本的更新，打开程序更新即可。

**我的账号密码安全吗？**
插件不保存明文密码，只保存账号名和游戏自己加密过的登录记忆（也就是勾选「记住密码」时游戏自己存的那一份）。数据只在电脑本地，除了检查更新时访问 GitHub，程序不联网。

**会修改游戏文件吗？**
只在游戏目录里新增 `winhttp.dll`（加载器）和 `SKKD9AccountSwitcher.dll`（插件本体）两个文件，不改游戏本身的任何文件。卸载后游戏目录恢复原样。

**数据存在哪里？**
都在 `%LOCALAPPDATA%\SKKD9AccountSwitcher\`：账号列表 `profiles\accounts.txt`、运行日志 `SKKD9AccountSwitcher.log`、安装记录 `install-record.json`、程序设置（代理地址）`launcher-settings.json`、窗口大小和隐藏快捷键 `plugin-settings.ini`、最近一次签到结果 `auto-checkin-latest.txt`。

另外，程序每次打开时（设置了 Steam 启动选项的，每次退出游戏后也会）会把账号列表备份到程序所在文件夹的 `账号备份.txt`。万一账号列表丢了，退出游戏后把它复制回 `profiles\accounts.txt` 即可。备份里的登录记忆是加密的，只能在这台电脑、这个 Windows 用户下使用，**不要发给别人**，分享程序时也别把它一起打包。

**怎么卸载？**
退出游戏，打开程序点「卸载插件」。设置过 Steam 启动选项的，记得先把启动选项清空，否则下次启动游戏时又会自动装上；创建过每日签到任务的，先点「删除任务」。想连账号列表一起删掉，再手动删除 `%LOCALAPPDATA%\SKKD9AccountSwitcher` 文件夹即可，游戏自己的登录记忆不受影响。
